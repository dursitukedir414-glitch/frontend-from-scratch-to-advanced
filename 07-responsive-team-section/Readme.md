# Responsive Team Section

## Description

This project is a responsive team section built using HTML and CSS. It displays three team member cards containing a name, role, and short description.

## Features

* Responsive design
* Flexbox layout
* Three team member cards
* Mobile-friendly interface

## Technologies Used

* HTML5
* CSS3

## CSS Concepts Used

* display: flex
* gap
* flex-direction
* padding
* border-radius
* media queries

## Desktop Layout

The cards are displayed in a single row.

## Mobile Layout

The cards are displayed in a single column.
