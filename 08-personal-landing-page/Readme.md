# 👨‍💻 My portfolio

This is My portfolio built using HTML and CSS. It shows basic personal information, skills About me.

## 📌 Project Overview

The project is a single web page that displays a profile card with:
- Profile picture
- Name and role
- Short bio/description
- Skills section
- Social media links (like GitHub, LinkedIn, etc.)

## 🛠️ Technologies Used

- HTML5
- CSS3
